NORI V0.2.7 — запуск на телефоне через домашнюю Wi-Fi сеть

1) На компьютере установите Node.js 18 или новее.
2) Не открывайте index.html через file:// для профиля/аккаунтов; используйте START_NORI_WINDOWS.bat.
3) Не закрывайте окно сервера.
4) Узнайте локальный IPv4 компьютера: нажмите Win+R, введите cmd, затем ipconfig.
   Найдите IPv4 Address активного Wi-Fi/Ethernet адаптера (например, 192.168.1.25).
5) Подключите телефон к той же Wi-Fi сети.
6) На телефоне откройте http://192.168.1.25:3000, заменив пример IP на адрес своего компьютера.
7) Если не открывается, разрешите Node.js доступ в частной сети в Windows Firewall.
   Не отключайте firewall целиком и не публикуйте этот локальный сервер в интернете.

Важно: это локальный тестовый сервер. Для доступа из любой сети, постоянных аккаунтов и безопасного публичного запуска нужен развёрнутый HTTPS-сервер и дополнительные меры защиты.
