# Инструмент анализа НОРИ (необязательный, экспериментальный)

Игра от него не зависит. Нужны Python 3, numpy, scipy (`pip install numpy scipy`).

## Что делает
Ограниченный по глубине точный поиск одновременной игры с нулевой суммой. На каждом нетерминальном состоянии строится матрица 56×56 (14 связей × CREATE/CUT × committed/uncommitted) и решается линейным программированием (два LP, значения обязаны совпасть). Рекурсия идёт на заданное число раундов, результаты кэшируются по **полному** ключу: сеть + оба счётчика + вся карта повторений.

## Запуск
```
cd tools/analysis
python3 analyze.py --depth 2                 # стартовая позиция
python3 analyze.py --depth 3 --control       # контрольная позиция
python3 analyze.py --depth 2 --state my.json # {"edges":["1-2",...],"streak":[a,b],"seen":{"<маска>|a,b":count}}
```
`--time-limit N` — лимит секунд; если поиск не завершён, отчёт так и пишет и значение не выдаёт. Отчёты: `reports/*.json|csv|md`.
Контрольная позиция: кольцо без `3–4` и `1–10`, хорд нет, серия Белых 1, Чёрных 0, история = стартовая + текущая по одному разу.

## Как читать отчёт
- **Точные факты:** значение корня — точное значение игры, обрезанной на заданную глубину, при оценке границы 0.
- **Граница:** нетерминальные позиции на горизонте получают нейтральную оценку 0. Это НЕ ничья, а допущение о неисследованном продолжении.
- Значение — для Белых: +1 победа, −1 победа Чёрных. Равновесные стратегии не объявляются единственными.
- Если `seen` не задан во входном файле, предполагается, что позиция встречалась один раз (указано в отчёте).

## Проверка корректности
`test_analysis.py` (13 тестов): сверка Python-реализации правил с JS-движком на 3000 случайных состояний и на всех 78 400 парах конкретных выборов контрольной позиции, формат полного ключа совпадает с JS, разная история → разные ключи кэша, приоритет Signal Break над повторением, известные матричные игры, гарантии стратегий, симметрия при повороте на 180° (свойство инструмента, не независимый расчёт).
Оптимизаций, меняющих результат, нет; единственный сокращающий приём — точный: матрица из одних нулей имеет значение 0 без LP.
