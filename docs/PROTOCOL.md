# Протокол онлайн-режима НОРИ (версия 1)

Транспорт: WebSocket по адресу `/ws` того же сервера, который отдаёт страницу. Все сообщения — JSON-объекты в текстовом кадре, до 16 384 байт. В каждом сообщении (в обе стороны) есть `"v": 1` и `"type"`.
Сервер — единственный источник истины: состояние партии меняется только через `NORI.state.playRound` из движка локальной игры. Клиент не присылает ни статус committed, ни результат, ни состояние; лишние поля отклоняются.

## Клиент → сервер
| type | поля | смысл |
|---|---|---|
| `create_room` | необязательно `auth` | создать комнату; создатель играет Белыми (индекс 0) |
| `join_room` | `code`, необязательно `auth` | войти вторым игроком (Чёрные, индекс 1) |
| `resume_room` | `code`, `token` | вернуть своё место после обрыва или перезагрузки |
| `submit_choice` | `round` (целое), `choice` = `{node, action, edge}` | зафиксировать выбор текущего раунда |
| `request_snapshot` | — | получить публичный снимок |

`auth` — токен сессии аккаунта (как в `Authorization: Bearer`). Если оба места заняты разными аккаунтами, завершённая партия один раз меняет их рейтинг (Elo, K = 24). Гости и один аккаунт на обоих местах не учитываются. Некорректный `auth` даёт `INVALID_MESSAGE`, а неизвестный токен просто игнорируется.

Код комнаты: 6 символов из `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (без I, O, 0, 1), генерируется криптостойко. Регистр и пробелы по краям при вводе игнорируются.

## Сервер → клиент
| type | поля |
|---|---|
| `room_created` | `code`, `playerIndex`, `token`, `snapshot` |
| `room_joined` | `code`, `playerIndex`, `token`, `snapshot` (+ обоим `lobby_update`) |
| `room_resumed` | `code`, `playerIndex`, `snapshot` *(дополнение к минимальному списку)* |
| `lobby_update` | `code`, `you`, `opponentPresent`, `opponentConnected` |
| `choice_locked` | `round` — ваш выбор принят |
| `opponent_status` | `round`, `opponentLocked: true` — соперник зафиксировал выбор (только факт) |
| `round_resolved` | `round`, `choices` (оба), `record` (запись раунда движка), `snapshot` |
| `snapshot` | `snapshot` |
| `error` | `code`, `message` (английский запасной текст), иногда `round` |

`snapshot` = `{ code, game: {version, round, edges, streak, rounds, result}, seat: {index, youLocked, opponentLocked, opponentPresent, opponentConnected} }`. Он **никогда** не содержит неразрешённых выборов, только булевы флаги `youLocked`/`opponentLocked`. Карта повторений (`seen`) тоже не передаётся.

## Коды ошибок
`BAD_JSON`, `TOO_LARGE`, `INVALID_MESSAGE`, `UNKNOWN_TYPE`, `BAD_CODE`, `ROOM_NOT_FOUND`, `ROOM_FULL`, `BAD_TOKEN`, `ALREADY_IN_ROOM`, `NOT_IN_ROOM`, `OPPONENT_MISSING`, `ROUND_MISMATCH` (с актуальным `round`), `GAME_OVER`, `DUPLICATE_CHOICE`, `INVALID_CHOICE`, `RATE_LIMITED`, `SERVER_BUSY`, `INTERNAL` (без деталей и стека). Клиент показывает переведённый текст по коду.

## Места и токены
Токен — 24 случайных байта (base64url). Сервер хранит только его SHA-256 и сравнивает за постоянное время. Токен отправляется только владельцу места в `room_created`/`room_joined`, не попадает ни в какие другие сообщения и в логи. Новое соединение с тем же токеном заменяет старое (старое закрывается кодом **4001**; клиент в этом случае не переподключается).
Занятое место нельзя занять по одному коду: `join_room` в полную комнату даёт `ROOM_FULL`.

## Жизненный цикл и ограничения сервера
- Комнаты только в памяти процесса: при перезапуске сервера исчезают (клиент получает `ROOM_NOT_FOUND`).
- Комната удаляется через 30 минут, если оба места отключены, и через 6 часов без активности. Максимум 500 комнат, 1000 соединений.
- 30 сообщений за 10 секунд на соединение (`RATE_LIMITED`); после 10 нарушений соединение закрывается. Соединение без места закрывается через 30 с. Двоичные кадры отклоняются.
- Heartbeat: ping каждые 25 с, соединение без pong закрывается.
- Заголовок `Origin`, если он есть, должен совпадать с `Host` (или быть в `ALLOWED_ORIGINS`, список через запятую); иначе 403.
- Публично отдаются только `index.html`, `styles.css`, `src/*.js`, `tests/harness.js`, `tests/*.test.js`. Остальное (в том числе `server/`) даёт 404. `GET /health` → `{"ok":true}`.
