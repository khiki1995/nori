# Как включить вход через Google в NORI 0.2.7

На скриншоте NORI была открыта адресом вида `file:///C:/.../index.html`. В таком режиме браузер не подключается к серверу аккаунтов, поэтому кнопка Google остаётся выключенной. Сам OAuth-маршрут в проекте есть, но он намеренно не включается без клиентских данных Google.

## Шаг 1. Запустить NORI правильно

1. Закройте вкладку, в адресе которой начинается `file:///`.
2. В распакованной папке проекта дважды нажмите `START_NORI_WINDOWS.bat`.
3. Дождитесь окна Node-сервера и откройте `http://localhost:3000` (обычно браузер откроется автоматически).
4. В профиле сообщение «Сервер не подключён» должно исчезнуть. На этом этапе вход по электронной почте уже может работать, но Google всё ещё требует следующего шага.

Если окно сервера показывает ошибку `ws` или `npm install`, проверьте подключение к интернету и наличие Node.js 18+. Не закрывайте окно сервера, пока используете NORI.

## Шаг 2. Создать OAuth-клиент Google

1. Откройте Google Cloud Console и выберите или создайте проект.
2. Настройте экран согласия OAuth в соответствии с подсказками Google.
3. Создайте OAuth Client ID типа **Web application / Веб-приложение**.
4. В список **Authorized redirect URIs / Разрешённые URI перенаправления** добавьте точно:

   `http://localhost:3000/auth/google/callback`

5. Сохраните и скопируйте Client ID и Client Secret. Это не пароль от вашей учётной записи Google.

## Шаг 3. Сохранить настройки только на своём компьютере

1. В папке проекта скопируйте `.env.example` в новый файл с именем `.env`.
2. Откройте `.env` в Блокноте и заполните три строки, используя значения из Google Cloud Console:

   ```dotenv
   GOOGLE_CLIENT_ID=вставьте_сюда_Client_ID
   GOOGLE_CLIENT_SECRET=вставьте_сюда_Client_Secret
   GOOGLE_REDIRECT_URI=http://localhost:3000/auth/google/callback
   ```

3. Сохраните файл. Не публикуйте `.env`, не добавляйте его в архив и не отправляйте Client Secret в чат. `.env` исключён из Git.
4. Закройте окно сервера и снова запустите `START_NORI_WINDOWS.bat`.
5. Обновите `http://localhost:3000`. Кнопка «Продолжить с Google» должна стать доступной. При нажатии выберите Google-аккаунт и проверьте разрешения на странице Google.

## Как проверить статус настройки

Откройте `http://localhost:3000/api/oauth/google/status`. До настройки ожидается `"configured": false`; после корректного заполнения `.env` и перезапуска сервера — `"configured": true`.

Google должен принять redirect URI символ в символ. Для публичного сайта вместо localhost нужен зарегистрированный HTTPS-адрес вашего сервера. Не используйте локальный callback для входа с телефона через IP-адрес компьютера.

## Безопасность и ограничения прототипа

- Не вводите пароль Google в форму NORI. Вход должен проходить на сайте Google.
- Не отправляйте Client Secret в поддержку, в переписку или в открытый архив.
- Если email уже связан с обычным NORI-паролем, автоматического объединения аккаунтов пока нет.
- Текущий сервер использует локальное файловое хранение аккаунтов и не прошёл независимый аудит безопасности; пока не размещайте его в публичном интернете с реальными пользовательскими данными.
- Реальную авторизацию Google нельзя проверить без OAuth-клиента, созданного владельцем проекта. Автотесты могут проверить только состояние сервера и обработку ошибок.
